Your data, on your device

Compass stores conversation titles, colors, time totals, agent card text, and saved updates in Chrome’s local extension storage. Nothing is sent to a separate server. Export a backup at any time.

How the clock works

The selected Claude tab must be visible in a focused browser window. Interactions reset the idle timer. Switching conversations gives each chat its own totals. Leaving the browser stops the clock; it does not add idle time.
